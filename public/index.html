这个功能是做什么的

每个网址都有一个「详情」页，里面有简介、功能亮点、使用笔记、相关链接四栏。收藏的网址一多，一个个手写很费劲，时间久了也容易忘记某个网站当初是干什么用的。

这个功能让 AI 智能体替你做这件事：它读取你的网址列表，逐个打开看一遍，把四栏内容填好。你只需要偶尔看一眼、改一改。

开始之前需要准备什么

一个能联网、能发 HTTP 请求的 AI 智能体。比如 Claude Code、Cursor 这类带工具的编程助手，或者你自己写的脚本。只能聊天、不能联网的 AI 用不了。

一步一步来

  1. 用智能体能访问到的地址打开本页。智能体和导航在同一台电脑上，用 localhost 就行；不在同一台，就要用局域网 IP 或域名打开，否则下面复制出来的地址它连不上。
  2. 决定要不要让它看私密网址。「允许访问私密网址」默认关闭，这时它只能看到公开网址。打开后，私密网址的地址和标题也会交给它（账号密码仍然不会）。拿不准就先关着。
  3. 填管理密码（进入管理员模式时输入的那个），点「生成令牌并启用」。页面上会出现一串以 nav_ 开头的令牌。它只显示这一次，关掉设置就看不到了。
  4. 点「复制说明」。这时说明里已经自动带上了刚生成的令牌和本站地址。
  5. 把说明粘贴给你的智能体，再加一句「请按这份说明，为我导航里还没有详情的网址补全详情」。
  6. 等它跑完，回来检查。右键任意网址 → 查看详情。页面底部的「记录」里会写明这份详情是「由智能体编辑」还是「由你编辑」。不满意的地方直接点各栏目标题旁的编辑按钮修改。

它能做什么，不能做什么

  • 能：读取网址的标题、地址、描述、标签、所属分类；写入详情的四栏；顺手改描述和标签。
  • 不能：读取或修改账号、密码、备注和自定义字段；新增或删除网址；改分类；改公开/私密；改任何设置。

常见问题

智能体说连不上、请求超时
多半是地址问题。看说明里的「基础地址」：如果是 localhost 而智能体在别的机器或云端，它访问的其实是它自己。换一个它能访问的地址重新打开本页，再复制一次说明。
智能体说 401、令牌无效
令牌复制不完整，或者之后又重新生成过（旧令牌会立刻失效），或者已被停用。重新生成一个再试。
有些网址它没处理
私密网址在开关关闭时它看不到；需要登录才能看、或者打不开的网站，它也可能跳过。这是正常的，说明里也要求它「看不懂就跳过，不要编造」。
令牌忘记复制了
没法找回，库里只保存了它的校验值。重新生成一个即可。
以后新加的网址怎么办
再让智能体跑一次就行，它只会处理还没有详情的。想全自动的话，可以填「新网址通知地址」：每次添加网址，导航会把编号、标题和地址推送到那个地址，由你的智能体服务接收后立即处理。这需要你那边有一个能接收请求的服务，不需要的话留空。
它写得不对怎么办
直接在详情页手动改。AI 写的内容可能有错，尤其是收费情况、功能细节这类容易过时的信息，重要的请自己核对。

安全提醒

  • 不要把运行智能体的机器加进 IP 白名单。白名单内的设备不需要令牌就能使用全部功能，包括读取账号密码，等于绕过了上面所有限制。
  • 令牌相当于一把钥匙，拿到的人可以读你的网址列表、改详情。怀疑泄露了就点「重新生成令牌」或「停用」。
  • 不用的时候可以随时「停用」，需要时再生成。
